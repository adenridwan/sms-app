Dua catatan dari pengujian:

Saya sempat kena "Too Many Attempts" — itu throttle:auth bekerja sebagaimana mestinya. Kalau Anda mengalaminya saat uji berulang, tunggu sebentar atau jalankan php artisan cache:clear.
Untuk uji kode akses sekali-pakai, buat dulu lewat menu web Pengaturan → Keamanan Login, lalu di layar login mobile pilih "Masuk dengan kode akses".
